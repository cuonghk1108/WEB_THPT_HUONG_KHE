## 🚀 How to Use

### For Development
```bash
# Clone
git clone https://github.com/cuonghk1108/WEB_THPT_HUONG_KHE.git

# Install
npm install

# Configure .env (see README.md for details)
cp .env.example .env

# Run
npm run dev

# Access: http://localhost:3000
```

### For Deployment
```bash
# Build
npm run build

# Deploy to Vercel
vercel --prod

# Access: https://thpthuongkhe.vercel.app
```

### For Admin
1. Visit: https://thpthuongkhe.vercel.app/admin/login
2. Login with: admin / admin
3. Manage all content from dashboard
4. Data auto-syncs to cloud
