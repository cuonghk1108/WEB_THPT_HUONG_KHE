# Folder Upload

Folder này dùng để lưu trữ các file ảnh được upload bởi admin.

## Cấu trúc:
- `/uploads/images/` - Ảnh chung của website
- `/uploads/news/` - Ảnh cho tin tức
- `/uploads/gallery/` - Ảnh cho thư viện
- `/uploads/teachers/` - Ảnh giáo viên
- `/uploads/clubs/` - Ảnh câu lạc bộ

## Lưu ý:
- File sẽ được đặt tên theo UUID để tránh trùng lặp
- Hỗ trợ định dạng: JPG, PNG, GIF, WEBP
- Kích thước tối đa: 5MB
